# Prompt de entrega

Copia el bloque de abajo y pégalo en Claude Code (app de escritorio, terminal o web), abierto en una carpeta vacía.
Claude descarga el kit, revisa que tengas todo instalado, te muestra un ejemplo y te va haciendo preguntas hasta
convertir tu plano en 3D.

---

```
Quiero convertir un plano en 3D con calidad profesional.

1. Clona https://github.com/La-Boveda-del-Master/kit-mapa-3d y trabaja dentro de esa carpeta.
2. Lee CLAUDE.md y sigue el skill mapa-3d (.claude/skills/mapa-3d/SKILL.md) de principio a fin.
3. Revisa que tenga Python, las librerías de requirements.txt y Blender. Si falta algo, dime cómo instalarlo
   antes de seguir.
4. Construye uno de los ejemplos y muéstrame sus renders, para ver la calidad antes de empezar.
5. Entrevístame con docs/ENTREVISTA.md. Pídeme el plano y lo que necesites, una cosa a la vez.
6. Muéstrame renders y el mapa web en cada avance. Pasa el control de calidad antes de entregarme.
   No publiques nada en internet sin preguntarme.

Mi lugar es: [qué es y dónde queda: oficina, casa, edificio, campus, local, evento...]
Mi plano está en: [PDF / DWG o DXF / imagen / lo dibujo a mano]
Lo quiero para: [renders e impresión / mapa web / video / todo]
```

---

Requisitos:
- Claude Code: https://claude.com/claude-code
- Python 3.10 o superior
- Blender 4.2 o superior (probado en 5.2), gratis en https://www.blender.org

Lo demás lo instala o lo explica Claude.
