# Prompt de entrega

Copia el bloque de abajo y pégalo en Claude Code (app de escritorio, terminal o web), abierto en una carpeta vacía.
Claude clona el kit, revisa que tengas todo instalado y te va haciendo las preguntas para montar tu mapa.

---

```
Quiero crear el mapa 3D navegable de un recinto para un evento.

1. Clona https://github.com/La-Boveda-del-Master/kit-mapa-3d-recinto y trabaja dentro de esa carpeta.
2. Lee CLAUDE.md y sigue el skill mapa-3d-recinto (.claude/skills/mapa-3d-recinto/SKILL.md) de principio a fin.
3. Revisa que tenga Python, las librerías de requirements.txt y Blender. Si falta algo, dime cómo instalarlo
   antes de seguir.
4. Construye primero el ejemplo demo para comprobar que todo funciona y muéstramelo.
5. Después entrevístame con docs/ENTREVISTA.md. Pídeme el plano (PDF) y lo que necesites, una cosa a la vez.
6. Muéstrame renders y el visor en cada avance. No publiques nada en internet sin preguntarme.

Mi recinto es: [nombre del recinto y ciudad]
Mi evento es: [nombre y fechas]
```

---

Para usar el kit hace falta:
- Claude Code: https://claude.com/claude-code
- Python 3.10 o superior
- Blender 4.2 o superior (probado en 5.2), gratis en https://www.blender.org

Lo demás lo instala o lo explica Claude.
